# WhatsApp API & Customer Service Chatbot

## Original Upwork Job Post

### Summary
We need a developer to implement a WhatsApp API and chatbot for customer service. The work includes setting up the WhatsApp integration, building a chatbot to handle common customer inquiries, and connecting it to our existing systems. You should be able to configure the messaging flow, support automated responses, and help ensure the solution is reliable and easy to maintain. Experience with similar customer service automation projects is important.

### Client Problem Breakdown
- **Channel**: WhatsApp Business API.
- **Goal**: Automate common customer service inquiries, route inquiries, and integrate with backend systems.
- **Requirements**:
  - WhatsApp Business API integration (webhook verification, inbound/outbound messaging).
  - Conversational chatbot logic for common queries (e.g. order status, business hours, FAQ).
  - Integration with existing backend services (CRM, Order management, or Mock API).
  - Reliability, observability, and maintainability (resilient against network drops, bursts, and API rate limits).
